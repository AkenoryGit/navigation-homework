Основной функционал:

 Профиль пользователя
 - Авторизация через Firebase Auth
 - Регистрация нового аккаунта
 - Локальное хранение данных пользователя через Realm
 - Смена пароля
 - Изменение никнейма
 - Установка аватарки из галереи
 - Просмотр аватарки в полноэкранном режиме
 
 Лента постов
 - Создание постов с:
   текстом
   фотографией
   музыкальным треком
 - Добавление лайков двойным тапом + анимация “сердечка” (как в Instagram)
 - Отображение лайков и просмотров
 - Загрузка пользовательских изображений через FileManager
 - Корректное отображение авторов и динамическое обновление никнейма
 
 Избранные посты
 - Добавления постов в избранное / удаления
 - Избранное хранится персонально для каждого пользователя
 - Возможность проигрывать прикреплённую музыку
 
 Музыкальные треки
 - Список встроенных треков
 - Выбор трека при создании поста
 - Проигрывание аудио внутри приложения
 
 VK Видео
 - Поддержка сохранения видео по ссылке
 - Встроенный просмотр (WKWebView)
 - Поиск по видео
 - Удаление свайпом
 - Два дефолтных видео для каждого нового пользователя
    
 Настройки
 - Выбор темы приложения:
   автоматическая
   светлая
   тёмная
 - Изменение никнейма
 - Смена пароля (Realm)
 - Персональные настройки сохраняются через UserDefaults
 
 Карта
 - Простая карта на основе MapKit
 - Отображение местоположения пользователя
 - Построение маршрута при длительном тапе на карте
 
 Уведомления
 - Запрос разрешения на отправку локальных уведомлений
 - Ежедневное уведомление с напоминанием просмотреть обновления
 
 Архитектура проекта
 - Приложение построено на UIKit
 - Используется структура Coordinator:
   AppCoordinator — старт приложения
   ProfileCoordinator — навигация внутри профиля
 - Логика разбита по модулям:
   Profile
   Feed
   Favorites
   VKVideos
   Music
   Settings
 - Хранение данных:
   Realm — данные пользователя, никнейм, пароль, аватарка
   UserDefaults — настройки темы, избранное, VK-видео
   Firebase Auth — регистрация и вход
   
 Используемые технологии
 - UIKit
 - Auto Layout (код)
 - Realm
 - Firebase Auth
 - MapKit
 - WebKit
 - URLSession
 - UserDefaults
 - FileManager
 - NotificationCenter
 - UNUserNotificationCenter
 - Coordinator pattern
 - Custom Cells + динамическая высота таблиц
